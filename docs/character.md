# 换角色指南

STBridge 默认的角色是藤田琴音，但并不是只能用琴音。这篇告诉你，换成别的角色时要改哪些地方，以及每一项在控制台的哪一页（控制台地址是 `http://127.0.0.1:11453/`）。

先看全貌：

| 要改的 | 在哪里改 |
| --- | --- |
| 角色卡、人设 | ST |
| 昵称（也是唤醒词）、ST 角色名 | 控制台“角色和情绪”页 |
| 情绪列表 | 控制台“角色和情绪”页 |
| 每种情绪的语音 | 控制台“角色和情绪”页 |
| 每种情绪的表情包 | 控制台“表情包”页 |
| 好感度的档位和态度 | 控制台“好感度”页 |
| RVC 声音模型 | 控制台“唱歌”页 |
| 定时消息、主动搭话的内容 | 控制台“定时计划”页 |
| 出错、排队、点歌时的固定回复 | 控制台“系统 › 回复文案” |
| 注入给模型的规则 | 控制台“ST 注入”页，改完到 ST 点“同步” |

不用一口气全改完。按表格从上往下改，改到能正常聊天就可以先用起来，剩下的慢慢补。

## 1. 准备角色卡

先在 ST 里准备好新角色的角色卡，确认在 ST 里能正常聊天。STBridge 不提供角色卡，也不会改动你的角色卡。

**好感度不依赖 MVU，也不依赖任何 ST 变量，普通角色卡就能用。** 好感度是 STBridge 核心自己记的：模型在回复里写 `_.add('<ST 角色名>.好感度', 数值)`，核心读到后更新数值；注入的规则再通过 `{{stbridge_*}}` 宏，把这一轮说话人的好感度、档位和态度告诉模型（见第 10 节）。

如果你装了酒馆助手（TavernHelper，也叫 JS-Slash-Runner），STBridge 还会在每轮生成之前，把当前说话人的好感度写进最新一楼的 `stat_data.<ST 角色名>.好感度[0]`，方便你自己的世界书或 MVU 变量读取，比如让世界书随好感度切换内容。没装酒馆助手，或者聊天里还没初始化过 `stat_data`，这一步会直接跳过，不影响回复，也不影响好感度的记录。没有这种需求的话，不装就好。

## 2. 昵称和 ST 角色名（“角色和情绪”页）

在“角色和情绪”页的“角色”一栏点“＋ 添加角色”，或者在“管理角色”里修改已有的角色。表单里这几项要留意：

- **角色名称**：只在控制台里用来区分角色。
- **昵称**：同时也是唤醒词，群里大家叫它的就是这个名字。各处固定回复里的 `{昵称}` 也会换成它（见第 9 节）。
- **ST 角色名**：好感度变量的名字，变量路径是 `<ST 角色名>.好感度`，模型更新好感度时用的就是它。用注入功能的话，`{{stbridge_affinity_var}}` 宏会自动把它告诉模型，你不用手写。起一个固定的名字就好，建议和角色名一致，之后别经常改。只有当你自己的世界书或 MVU 要按 `stat_data.<名字>.好感度` 读取时，才需要和那边写的保持一致。
- **绑定模型**：这个角色用哪个 GPT-SoVITS 模型。用 Irodori 的话不用管。
- **默认情绪**：回复里没写情绪标签时，用哪种情绪。

保存以后，控制台里显示角色名的地方都会跟着变，比如“系统 › 回复文案”里会显示新的昵称。

只打算用一个角色的话，直接改现有的就行。想把琴音也留着，就另外添加一个角色，再把新角色设为默认角色。

## 3. 情绪列表（“角色和情绪”页）

模型每次回复都要带一个情绪标签 `[情绪:xxx]`，xxx 只能从你这里配置的情绪中选。当前角色有哪些情绪，注入的规则会自动告诉模型。

选好角色后，在“选择角色后查看情绪”一栏点“＋ 新建覆盖”，就能添加一种情绪。名字可以用字母、数字、下划线、横线和汉字，最长 40 个字。每种情绪都能单独设置语音和表情包，见下面两节。

情绪名要和语音、表情包的分组对得上。情绪不用太多，留几种常用的就够了。

## 4. 每种情绪的语音（“角色和情绪”页）

先到“语音”页选好引擎：GPT-SoVITS 或 Irodori。

**用 Irodori**：在每种情绪的卡片里填 caption（一句日文的语气描述）和句首表情，不需要参考音频。没填 caption 的情绪，会用“语音”页里的 default_caption。角色的音色由 Irodori 的 LoRA 决定（“语音”页的 `lora_adapter`），换角色时要换成新角色的 LoRA。

**用 GPT-SoVITS**：给每种情绪准备 3 到 10 秒的参考音频，在“新情绪（上传参考音频）”里上传。文件会按 `<参考音频根目录>/<情绪>/<参考文本>.wav` 存放，也就是说，文件夹名是情绪名，文件名是参考文本。同一种情绪可以放好几段，发语音时随机挑一段。GPT 和 SoVITS 的模型权重，要先在“语音”页的“添加模型”里登记，再到第 2 节的“绑定模型”里选上。

参考音频和模型都要你自己准备，STBridge 不附带。

## 5. 每种情绪的表情包（“表情包”页）

在“表情包”页给每种情绪上传图片，支持 PNG、JPG 和 GIF。回复带的是哪种情绪，就从对应的分组里随机挑一张发出去。你还可以设置发送概率，以及同一个会话里的冷却时间。某种情绪没有分组，或者分组里没有图片的话，就不会发表情包。

## 6. 好感度（“好感度”页）

好感度分两条线：一条是所有者，也就是主人；另一条是群友。

- 所有者的角色名和昵称跟随默认角色，在“角色和情绪”页改（见第 2 节）。
- **所有者档位、群友档位**：每一档都有名字、分数范围和态度描述。档位名和态度描述会通过宏发给模型，所以换了角色以后，最好把每一档的态度描述改成符合新角色性格的说法。
- **群友变量名、群友发言前缀**：前者是群友好感度用的变量名，后者是群聊消息开头加的标记。用注入功能的话不用管，模型通过宏就能拿到；只有你自己手写预设或世界书时，才需要和这里保持一致。
- 另外，“新用户初始值”和“每次变化上限”也可以按需要调。

## 7. RVC 声音模型（“唱歌”页）

翻唱要用新角色的 RVC 声音模型：

1. 自己训练或准备好模型，放进 RVC 整合包的 `assets/weights` 文件夹。
2. 在“唱歌”页的“翻唱参数”标签里，从“声音模型”下拉框选中它；有对应的 index 文件的话，也一起选上。
3. 每个角色的音高不一样，可以调“人声升降调”，也可以在“升降调预设”里设置“男声”“女声”这类关键词。

不用翻唱的话，这一节可以跳过。

## 8. 定时消息和主动搭话（“定时计划”页）

- **定时计划**：每个计划都有“要求”和“备用文字”。“要求”会交给 ST，让角色用自己的口吻写出这条消息；“备用文字”是 ST 出问题时的兜底，会随机发其中一句。自带的计划是照着琴音写的，换角色以后请逐个看一遍，改成新角色的说法，用不上的直接删掉。
- **主动搭话**：有一个“提示”，同样改成适合新角色的内容。

## 9. 固定回复（“系统 › 回复文案”）

出错、排队、点歌时，机器人会说一些固定的话，都在“系统”页的“回复文案”标签里。文案里的 `{昵称}` 会自动换成当前角色的昵称，所以大部分不用改。如果觉得语气和新角色不搭，可以逐句改成它的口吻。每句 1 到 100 个字；标着“每行一句”的项目，每次会随机挑一句。

## 10. 注入规则（“ST 注入”页）

STBridge 写进预设和世界书的内置条目，都可以在“ST 注入”页编辑：

| 条目 | 作用 |
| --- | --- |
| 对话文风 | 让角色像在 QQ 上聊天一样说话，不写旁白和动作 |
| 身份识别 | 区分说话的是主人还是群友 |
| 字数要求 | 每次发言写多长 |
| 中日双语 | 让回复写成“日语原文 + 中文翻译”（语音读的是日语） |
| game 标签 | 把正文放进 `<game></game>` |
| 情绪标签 | 让回复带上 `[情绪:xxx]`，xxx 从你的情绪列表里选 |
| 唱歌标签 | 答应唱歌时写 `[唱歌:歌名]`，不能唱时婉拒 |
| 好感度态度 | 把这一轮的好感度档位和态度告诉模型（写进世界书） |
| 好感度更新规则 | 让模型用 `_.add` 更新好感度（写进世界书） |

条目里用的是 `{{char}}` 和 `{{stbridge_*}}` 这样的宏，发给模型时会自动换成当前角色和这一轮的实际值，所以换角色时一般不用动它们。

**要特别留意的是“中日双语”这一条。** 它让回复写成“日语原文 + 中文翻译”，因为语音合成读的是日语。新角色不用语音，或者你想换成别的语言，可以改这条的文字。不过核心是靠 `☆‹日语›` 加 `"中文"` 这种成对的格式来提取台词的，回复里没有这种格式，就会被当成格式不对。所以不要随便把这一条关掉。

改完保存后，回到 ST 的“ST Bridge”面板，在“注入”标签里点一次“同步”，改动才会真正写进预设和世界书。

## 11. 存成一套，方便切换（侧栏底部的总预设）

一套设置调好以后，点控制台侧栏最下面的“总预设”，在弹出的窗口里点“把当前设置另存为预设”。预设会保存全部设置，包括语音、情绪、表情包、定时计划、唱歌、好感度规则、回复文案等。但它不包括好感度数值、歌库、表情包图片这些文件，也不包括 API 密钥和端口。

以后想换回琴音，或者换成第三个角色，点侧栏最下面的“总预设”切换就行。切换前会自动存一份“切换前”的存档，随时可以退回去。预设还能导出成文件，也能导入别人分享的预设。

要注意，ST 里的角色卡、预设、世界书，以及语音、表情包这些文件，都不在总预设里。换角色时，这些要你自己一起换。
