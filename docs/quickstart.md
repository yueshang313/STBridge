# 快速开始

这篇带你从零开始，一直走到在 QQ 上收到角色的第一条回复。

SillyTavern、NapCat、AstrBot 这些软件需要你先自己装好，这里不讲它们怎么安装，只讲装好以后怎么和 STBridge 连起来。

## 先认识几个名字

- **ST**：SillyTavern，即酒馆，RP 最常用的和角色聊天的程序。
- **核心**：STBridge 的主程序。它在 QQ 和 ST 之间传话，语音、表情包、翻唱也都由它处理。
- **控制台**：核心自带的设置网页，地址是 `http://127.0.0.1:11453/`，几乎所有设置都在这里改。
- **主人**：就是你。机器人只回主人的私聊，别人私聊它不会理。

## 1. 准备工作

先确认下面几件事已经做好：

- **ST 能正常用**：模型 API 配好了，也有一个能正常聊天的角色。我们是在 ST 1.19.0 上测试的。
- **QQ 平台选好了，并且能登录**。两种二选一：
  - NapCat：拿一个 QQ 小号当机器人，不需要 AstrBot。NapCat 不是腾讯官方的程序，有封号风险，请一定用小号。
  - AstrBot：用 QQ 官方机器人，需要先在 AstrBot 里把 QQ 官方机器人平台配好。

  以后可以随时在控制台里切换平台。你已经装好了哪个，就先用哪个。
- **酒馆助手（可选）**：也叫 TavernHelper 或 JS-Slash-Runner。不装完全没问题，好感度是 STBridge 自己记的。装了的话，STBridge 会把好感度额外写进 ST 的变量里，方便你在自己的世界书里用，详见[换角色指南](character.md)。

## 2. 下载并启动

从 Releases 页面下载最新的 `STBridge-<版本号>.zip`，解压到一个固定的地方，比如 `D:\STBridge`。

双击 `start.bat`，会弹出一个命令行窗口，过几秒浏览器会自动打开控制台。这个窗口就是 STBridge 本身，用的时候一直开着，关掉就等于退出。

第一次启动后，文件夹里会多出一个 `data` 目录，你所有的设置和上传的文件都在里面。以后更新或者换电脑，保留好它就行。

## 3. 填路径、装扩展

在控制台左边点开“安装与路径”页。

1. 在“路径”一栏找到 SillyTavern，点“浏览…”，选你的 ST 文件夹（平时启动 ST 的那个文件夹，或者它里面的 `data` 文件夹都可以）。用 AstrBot 的话，把 AstrBot 的文件夹也填上。其他几项（NapCat、GPT-SoVITS、Irodori、RVC）现在用不到，空着就好。
2. 点页面底部的“保存”，再点“检查路径”。每一项都会显示能不能用，不能用也会说明原因。SillyTavern 这一项能用，才能继续往下做。
3. 在“ST 扩展”一栏点“安装”。装好后切到 ST 的页面刷新一下，扩展就加载出来了。
4. 用 AstrBot 的话，再到“AstrBot 插件”一栏点“安装”，然后去 AstrBot 的管理面板里重载这个插件（重启 AstrBot 也行）。

不用担心装坏，每次安装或卸载之前，旧文件都会先备份到 `data\backups`。

> **控制台的一个习惯**：改了输入框或勾选框以后，页面底部会出现保存栏，点了“保存”才算数。而“安装”“上传”“启动”这类按钮，点了就立刻执行。

## 4. 让 ST 连上核心

1. 点 ST 顶部的扩展图标（积木形状），在扩展列表里找到“ST Bridge”并展开，切到“桥接”标签。
2. “bridge 端口”保持默认的 `11452` 就行。它要和控制台“系统 › 端口”里的 bridge 端口一致，你没改过的话两边本来就一样。
3. 在 ST 里打开要在 QQ 上扮演的角色，切到要用的聊天，然后回到面板点“绑定当前角色和聊天”。
4. 点“启动桥接轮询”。

QQ 上的消息会一条条追加到你绑定的聊天里，所以最好专门新建一个聊天来绑定，别和你平时自己玩的聊天混在一起。

绑定只用做一次。第一次要手动点“启动桥接轮询”，以后刷新 ST 或者切回这个聊天，它都会自动开始。想暂停就点“停止桥接轮询”。

## 5. 连上 QQ

### 用 NapCat

1. 在控制台打开“系统”页的“聊天平台”标签，找到“NapCat 连接”这一栏。这里有连接地址和令牌（Token）。令牌默认是隐藏的，点“显示”就能看到，两项旁边都有“复制”按钮。
2. 打开 NapCat 的网页管理界面（WebUI），进入“网络配置”，新建一个“WebSocket 客户端”：
   - URL 填刚才复制的地址，默认是 `ws://127.0.0.1:11455/onebot`；
   - Token 填刚才复制的令牌；
   - 消息格式选 `array`；
   - 保存，记得勾上启用。
3. 回到控制台，“NapCat 连接”这一栏会显示“已连接”和小号的 QQ 号。
4. 还是在“聊天平台”标签里，再设三项：
   - “使用的平台”选“NapCat（QQ 小号）”；
   - “NapCat 主人 QQ 号”填你自己的 QQ 号；
   - “NapCat 群白名单”填允许机器人说话的群号，一行一个。白名单是空的，它在哪个群都不会说话。
5. 点底部的“保存”，马上生效，不用重启。

令牌只在你自己的电脑上有用，不过也别发给别人，截图时也注意遮住。

### 用 AstrBot

1. 保持 `start.bat` 的窗口开着，AstrBot 里的插件会自己连上核心，先开哪个都行。插件只负责传话，不会帮你启动核心。
2. 在控制台“系统”页的“聊天平台”标签里，“使用的平台”选“AstrBot（QQ 官方机器人）”（默认就是它），然后保存。
3. 在 QQ 上私聊机器人，发一句 `/stbridge_ping`（要不要加唤醒词，看你的 AstrBot 设置）。有回复，就说明插件加载好了。

## 6. 设置主人

机器人只回主人的私聊，所以这一步不能跳过，不设主人的话，它一条私聊都不会回。

- **用 NapCat**：上一步填的“NapCat 主人 QQ 号”就是，不用再设。
- **用 AstrBot**：打开“系统”页的“常规”标签，找到“主人”，填两项：
  - 平台 ID：AstrBot 里这个机器人平台的 ID，比如 `qq_official`；
  - 发送者 ID：你在这个平台上的 ID。QQ 官方机器人看到的不是 QQ 号，而是一长串字符，可以用 AstrBot 自带的 `/sid` 指令查到。

  这两项要和 AstrBot 里显示的一字不差，填好立刻生效。

群里的规矩不一样：不管是谁，都要 @ 它或者叫它的名字，它才会回。NapCat 只在白名单里的群说话，AstrBot 则是在机器人所在的群里说话。好感度也是分开记的，主人单独一份，群友每人各一份。

叫它名字用的是唤醒词，也就是角色的昵称。默认角色叫琴音，所以在消息开头写“琴音”或“/琴音”就行；用 AstrBot 的话，按 AstrBot 里设置的唤醒前缀来。昵称可以在“角色和情绪”页修改。

## 7. 注入规则

STBridge 需要模型按一套固定的格式回复：带上情绪标签，正文放进 `<game>` 标签，台词写成日语加中文翻译，唱歌时写唱歌标签，还要更新好感度。这套规则不用你自己写，用“注入”功能一键写进 ST：

1. 在 ST 的“ST Bridge”面板里切到“注入”标签。
2. 点“同步”。它会把规则写进你当前正在用的预设，同时建一个叫“STbridge”的全局世界书。

它只增删带 STbridge 标记的条目，你自己的预设条目和世界书不会被改动。改预设之前，它还会先备份原来的预设。想恢复原样，点“移除”就行。

另外几点：

- 目前只支持 Chat Completion（聊天补全）类型的预设。用其他类型的话，写进预设的那部分会被跳过。
- 规则的文字在控制台的“ST 注入”页里改，可以关掉某条、调整顺序，或者加你自己的条目。改完保存后，记得回 ST 再点一次“同步”。规则是 ST 扩展写进去的，不同步的话，ST 那边还是旧的。
- 换了 ST 预设以后，也要在新预设上再点一次“同步”。
- 内置规则默认让角色用“日语台词 + 中文翻译”回复，因为语音合成读的是日语。如果你的角色不适合这样，请看[换角色指南](character.md)。

## 8. 发第一条消息

先确认三件事：`start.bat` 的窗口开着，ST 的页面开着，聊天已经绑定并开始轮询。

然后用你自己的 QQ 私聊机器人，随便说句“你好”。等几秒，角色的回复就会出现在 QQ 上。

一直没回复的话，先打开控制台的“总览”页。上面有一条链路：平台 → 核心 → ST 扩展 → 模型回复 → 语音 → 翻唱，哪一环没亮绿灯，问题就出在哪。在其他页面，如果顶部出现红色或黄色的横幅，它也会直接告诉你哪里出了问题。还解决不了，就看看文末的常见问题。

## 9. 进阶：语音、翻唱和表情包

这几样都不是必须的。先把聊天跑通，以后想加再回来看。这里只说要准备什么、在控制台哪里设置。

### 语音

Irodori 和 GPT-SoVITS 二选一。先自己装好其中一个、准备好模型，再到“安装与路径”页填上它的文件夹。然后去“语音”页选引擎。打开“自动启动服务”的话，需要发语音时，STBridge 会自动把语音服务开起来。

两种引擎控制语气的方式不一样：

- Irodori 不需要参考音频，靠每种情绪的 caption（一句日文的语气描述）和句首表情来控制语气；
- GPT-SoVITS 需要参考音频，每种情绪一个文件夹。

这些都在“角色和情绪”页里，在每种情绪的卡片中设置。

### 翻唱

需要你自己装好 RVC 整合包，并训练或准备好角色的声音模型。在“安装与路径”页填上 RVC 的文件夹，然后到“唱歌”页上传歌曲、选声音模型、调参数。

想用“整体升降调”的话，还要在“安装与路径”页的“额外依赖”里，点一下 pedalboard 旁边的“安装”。

### 表情包

自己准备好 PNG、JPG 或 GIF 图片，到“表情包”页按情绪分组上传，再打开“启用表情包”。

## 10. 更新到新版本

1. 下载新版的 zip，解压出来。
2. 关掉正在运行的 `start.bat` 窗口。
3. 把新版的文件全部复制到旧文件夹里覆盖，**只有 `data` 文件夹不要动**，你的设置都在里面。
4. 重新双击 `start.bat`。
5. 如果新版的更新说明里提到 ST 扩展或 AstrBot 插件有变化，到“安装与路径”页重新点一次对应的“安装”，然后刷新 ST、重载 AstrBot 插件。

## 推荐设置

- 预设用 Chat Completion 类型，规则交给“注入”功能。这是我们测试得最多的组合，也最省心。
- 想调整每次回复写几句、每句多长、情绪标签怎么用，这些都是注入规则里的条目（比如内置的“字数要求”和“情绪标签”）。到控制台“ST 注入”页改，改完回 ST 点“同步”。
- 想让每组台词分成几条消息发出去，更像真人在打字，可以到“语音”页的“通用设置”里打开“分条发”，再设好间隔时间和最多发几条。
- 角色现在的心情和今天的各项统计，在“总览”页看；角色的昵称、情绪、语音，在“角色和情绪”页改。
- 调出一套满意的设置后，到“系统”页的“总预设”里存一份，以后一键就能切回来。

## 常见问题

### QQ 上收到“琴音现在不在线哦，晚点再来找我～”

（“琴音”会换成你角色的昵称，下面其他固定回复也一样。）

这说明核心没开，或者 ST 没连上。按顺序检查：`start.bat` 的窗口还在不在；ST 的“ST Bridge”面板里有没有绑定聊天，轮询有没有在跑，没在跑就点“启动桥接轮询”。ST 页面刚刷新过或者被关掉过的话，要等它重新连上才行。

### 控制台显示 ST 扩展没连上

先确认扩展已经装好，并且装完以后刷新过 ST 页面。再看看 ST“ST Bridge”面板里的“bridge 端口”，和控制台“系统 › 端口”里的 bridge 端口是不是一样（默认都是 `11452`）。

### QQ 上收到“这次回复的格式不对，没能送达，请再说一次”

这是模型没按规定的格式回复，比如没有写成日语加中文的格式。最常见的原因是预设里没有注入规则，或者注入以后又换了预设。回 ST 的“ST Bridge”面板，在“注入”标签里点一次“同步”。还是不行的话，去 ST 里看看那条回复的原文，模型到底写了什么。

### 改了设置，好像没生效

控制台里改了输入框或勾选框以后，要点页面底部的“保存”才算数。如果改的是端口，还要重启核心：关掉 `start.bat` 的窗口，再双击一次就行，控制台里也有重启核心的按钮。

### 再次双击 `start.bat`，提示端口被占用

说明核心已经在运行了，或者端口被别的程序占了。一台电脑同时只能开一个核心，先看看是不是已经有一个窗口开着。

### 手机 QQ 能听语音，电脑版 QQ 放不出来

电脑版 QQ 放不了高采样率的语音。到“语音”页把“Output sample rate”设成 24 kHz（默认就是这个）。翻唱也一样，在“唱歌 › 翻唱参数”里选 24 kHz 单声道。

### 回复很慢，或者收到“现在找琴音的人太多啦，请稍后再来～”

好几个人同时说话时，机器人会按先来后到排队回复。排队人数的上限和最长等待时间，可以在“系统 › 常规 › 消息排队”里调。

### 定时消息、主动搭话一直没发出来

先到“定时计划”页确认功能已经打开，并且发送目标是你现在用的平台。NapCat 和 AstrBot 的会话是分开的，互相不通。

用 AstrBot（QQ 官方机器人）往群里主动发消息，还需要在 QQ 群设置里允许机器人主动发言。

另外，如果刚聊过天、ST 正在忙，或者正赶上安静时间，消息会往后推一推，等得太久也可能直接放弃。

### 不想让角色在某个群里说话

用 NapCat 的话，把这个群号从“NapCat 群白名单”里删掉；用 AstrBot 的话，把机器人移出这个群。
