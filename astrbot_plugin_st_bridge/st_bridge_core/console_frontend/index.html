      唱歌
      上传一首歌，琴音用 RVC 唱出来：去伴奏和混响、换成她的声音、再和伴奏混合。
      
        
      上传一首歌，琴音用 RVC 唱出来：去伴奏和混响、换成她的声音、再和伴奏混合。
      上传一首歌，琴音用 RVC 唱出来：先截取一段（默认从歌曲约 30% 处开始，60 秒），用 Roformer 模型去掉伴奏、再去掉人声里的混响，把干净的人声换成琴音的声音，再和伴奏混在一起。第一次处理需要加载模型，会比较慢；相同的歌和参数会直接用缓存。RVC 工作进程只在需要时启动，闲置一段时间后自动关闭。

      语音引擎设置、模型路径、角色和情绪参数都保存在核心数据目录（发布目录里的 data\config.json），修改后立即生效，不需要重启核心。保存采用临时文件加原子替换；配置损坏时控制台不会启动，也不会覆盖原文件。

      保存规则：改输入框、勾选框、下拉框、滑块只是修改，要点页面底部的“保存”才生效（有未保存的修改时才会出现保存栏）；按钮则是立即执行的动作，比如切换引擎、启动或关闭服务、上传、删除、立即试发。
